# Learning Outcomes

By the end of this chapter, students will be able to:

1. Describe what the Python interpreter is and how students interact with it from the command line.
2. Recognize common ways to run Python, including script mode, module mode, command mode, and interactive mode.
3. Explain the purpose of a virtual environment in simple, practical terms.
4. Create and activate a virtual environment for class work.
5. Use basic `pip` commands to inspect and install packages.
6. Explain why projects track dependencies in a `requirements.txt` file.
7. Apply simple setup practices that reduce confusion across machines and projects.
