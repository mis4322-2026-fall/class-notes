# Exercise 1: Compare Interpreter Entry Modes

## Task
Use the Python interpreter in three different ways and record what each mode is best for.

Run commands that demonstrate:

1. Script mode
2. Module mode with `python -m`
3. Command mode with `python -c`

If you need examples, you may use commands like these and adjust them for your machine:

```bash

python -c "print('health-check')"
```

Then answer these questions:

1. Which mode is best for a scheduled business script?
2. Which mode is best for a short diagnostic check?
3. Why is the REPL less suitable for repeatable operational work?

## Expected Deliverable
Submit:

1. The three commands you used
2. A one-line description of what each command demonstrates
3. Short answers to the three questions above

## Success Criteria
