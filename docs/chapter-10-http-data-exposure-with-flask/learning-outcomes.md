# Learning Outcomes

By the end of this chapter, you should be able to:

1. Explain the HTTP request/response cycle using the roles of browser, server, route, handler, and response.
2. Distinguish static responses from dynamic responses in a small web application.
3. Build minimal Flask routes that handle GET requests, read query parameters, and process basic form submissions.
4. Describe how Python data moves from a handler into an HTML template during server-side rendering.
5. Create small Flask examples that use only the core APIs needed for introductory business web workflows.
6. Query SQLite data in Python, shape the results into records, and render those records as HTML output.
7. Trace how a user action in the browser becomes data retrieval, processing, and a rendered page on the server.
