# Learning Outcomes

By the end of this chapter, you should be able to:

1. Parse JSON text into Python structures using `json.loads()` and `json.load()`.
2. Serialize Python dictionaries and lists to JSON text using `json.dumps()` and `json.dump()`.
3. Understand JSON structure: objects, arrays, primitive types, nesting, and `null` values.
4. Make HTTP GET requests using `requests.get()` and handle the returned Response object.
5. Interpret HTTP status codes and headers to assess request success or failure.
6. Extract and validate data from API response bodies using `.json()` and `.status_code`.
7. Handle missing fields, nested data, and type inconsistencies in API responses.
8. Use dictionary comprehensions and filtering to transform and aggregate API data.
9. Build a multistep workflow that fetches, validates, transforms, and aggregates API data for reporting.
10. Design API consumption workflows that are testable, traceable, and resilient to network and data quality issues.
