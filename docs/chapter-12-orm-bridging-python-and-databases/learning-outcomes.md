# Learning Outcomes

By the end of this chapter, you should be able to:

- Explain ORM as an abstraction layer between Python classes and relational database tables.
- Describe how Django model classes connect object attributes to stored data fields.
- Compare a simple raw SQL workflow to an equivalent Django ORM workflow at a conceptual level.
- Perform basic Django ORM CRUD actions using short, readable patterns.
- Use Django admin to view and edit model data for fast validation of business records.
- Connect Chapter 11 OOP concepts (class, instance, attribute, method) to ORM-based data work.
