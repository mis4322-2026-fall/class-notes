# Django Starter Project Reference (Chapters 12 and 13)

This starter project is a shared reference for both chapters:

- Chapter 12 (Django Part 1): ORM and data modeling
- Chapter 13 (Django Part 2): web app flow with URLs, views, templates, and admin

Use this structure as the baseline for walkthroughs and exercises.

## Structure

- `manage.py`
- `mis_portal/settings.py`
- `mis_portal/urls.py`
- `operations/models.py`
- `operations/views.py`
- `operations/admin.py`
- `operations/urls.py`
- `operations/templates/operations/project_list.html`

## Consistent Example Models

The examples in both chapters use the same model vocabulary:

- `Customer`
- `Project`
- `WorkItem`

These are intentionally simple so you can focus on concepts, not architecture.
