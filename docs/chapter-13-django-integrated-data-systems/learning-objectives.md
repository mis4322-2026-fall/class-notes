# Learning Objectives

This chapter shifts from Django data modeling to Django web application flow.

You will focus on:

- Understanding the request-to-response pipeline in practical terms.
- Mapping familiar MVC language to Django's MVT architecture.
- Building lightweight URL and view patterns for business use cases.
- Rendering model-backed data in templates for reporting and dashboards.
- Handling basic form submissions without deep framework internals.
- Using Django admin to support operational productivity.
