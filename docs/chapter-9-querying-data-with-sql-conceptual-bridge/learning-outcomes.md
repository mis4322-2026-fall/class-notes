# Chapter 9 Learning Outcomes

By the end of this chapter, you should be able to:

1. Explain how tables, rows, columns, primary keys, and foreign keys represent related business data.
2. Write basic SQLite queries using SELECT, WHERE, ORDER BY, and LIMIT.
3. Use INNER JOIN to combine records across multiple related tables.
4. Describe when LEFT JOIN can preserve unmatched rows and why that matters in reporting.
5. Run SQL queries from Python using sqlite3 and convert result rows into Python-friendly structures.
6. Load SQL query results directly into Pandas with pd.read_sql_query for analysis workflows.
7. Compare SQL-style filtering and aggregation with equivalent Python and Pandas data handling patterns.
