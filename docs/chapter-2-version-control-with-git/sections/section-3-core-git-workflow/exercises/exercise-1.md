# Exercise 1: Document the Basic Git Workflow

## Task
Using a practice repository, perform one small file update and record the basic Git workflow you used. Your workflow must include checking status, staging a change, committing it, and reviewing the commit history.

Use terminal commands only. Then explain the purpose of each command in plain language.

## Expected Deliverable
Submit:

- the exact command sequence you used
- one sentence for each command explaining its purpose
- the commit message you chose and a short reason it is clear

## Success Criteria
- The workflow includes `git status`, `git add`, `git commit`, and `git log`.
- Each command explanation is accurate and written in introductory language.
- The commit message describes the change clearly.
- The submission shows understanding of the difference between changing a file and saving a checkpoint.
