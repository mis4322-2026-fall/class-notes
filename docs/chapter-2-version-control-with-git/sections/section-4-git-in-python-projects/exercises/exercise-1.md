# Exercise 1: Identify What Git Should Track in a Python Course Project

## Task
Imagine you are starting a new Python course repository. Choose at least four files or file types that Git should track from the beginning, such as documentation, dependency lists, or source files.

For each choice, explain why it belongs in version control and how it helps with project organization or reproducibility.

## Expected Deliverable
Submit a short list that includes:

- at least four files or file types to track
- one practical reason for tracking each item
- one short concluding statement about how Git supports Python project setup

## Success Criteria
- The selected items are realistic for an introductory Python project.
- The reasons connect Git to organization, recovery, or reproducibility.
- The response includes more than just Python source files.
- The conclusion shows an understanding of Git as a project workflow tool.
