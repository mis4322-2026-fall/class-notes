# Exercise 1: Compare Manual Copies to Version Control

## Task
Imagine you are maintaining a class project folder over three weeks. Write a short comparison between these two approaches:

1. Creating new folders such as `project-v2`, `project-v3`, and `project-final`
2. Using a single Git repository with commits to track changes

Your comparison should explain how each approach affects organization, recovery after mistakes, and understanding project progress.

## Expected Deliverable
Submit a short response with:

- one paragraph comparing the two approaches
- one example of a mistake that is easier to recover from with Git
- one sentence explaining why version control matters in this course

## Success Criteria
- The response clearly distinguishes manual copying from tracked version history.
- The recovery example is practical and course-related.
- The explanation uses clear, introductory language appropriate for an student.
- The response shows why Git is useful before advanced programming topics begin.
