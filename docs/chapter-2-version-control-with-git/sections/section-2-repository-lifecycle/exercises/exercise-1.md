# Exercise 1: Trace a Repository from Setup to First Checkpoint

## Task
Create a small practice repository in a temporary folder on your machine. Use terminal commands to:

1. create the folder
2. initialize Git
3. add a file named `README.md`
4. inspect the repository state before and after the file is added

After completing the commands, write a brief explanation of how the repository changed from an ordinary folder into a tracked project folder.

## Expected Deliverable
Submit:

- the command list you used
- a short written explanation of the repository lifecycle in this example
- a brief note describing what changed in `git status`

## Success Criteria
- The command sequence correctly shows repository creation and inspection.
- The explanation identifies `git init` as the point where tracking begins.
- The response refers to `git status` as evidence for repository state changes.
- The write-up stays practical and avoids advanced Git terminology.
