# Learning Outcomes

By the end of this chapter, students will be able to:

1. Explain why version control is useful for coursework, collaboration, and project recovery.
2. Describe the basic lifecycle of a Git repository from creation through ongoing updates.
3. Use core Git commands to inspect changes, save work, and review project history.
4. Distinguish between a working directory, staged changes, and committed history.
5. Recognize how Git supports safer experimentation in technical projects.
6. Apply simple Git practices to Python course folders and project files.
7. Interpret common repository status information shown in the terminal.
