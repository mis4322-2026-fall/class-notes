# Advanced Python for MIS

This MkDocs project publishes the course textbook and exercise materials for the Advanced Python curriculum.

## Structure

- Course content lives under `docs/`.
- Each chapter remains self-contained in its own `chapter-<number>-<slug>/` folder.
- Section notes and exercises are published directly from the chapter folders.

## Current Content

- Chapter 1: Python Execution & Environment Management

## Local Preview

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open the local address reported by MkDocs.
