# Learning Outcomes

By the end of this chapter, you should be able to:

1. Define and call Python functions with parameters and return values to solve repeatable business data tasks.
2. Design functions that process list and dictionary inputs without mutating source data unless explicitly required.
3. Apply function decomposition to break one large data-processing step into smaller, testable components.
4. Use lambda expressions for short, focused transformations in sorting, filtering, and mapping scenarios.
5. Combine named functions and lambdas into readable pipelines for business reporting workflows.
6. Validate function behavior with unit tests that cover normal cases, edge cases, and empty inputs.
7. Select when to use a named function versus a lambda based on clarity, reuse, and maintainability.
