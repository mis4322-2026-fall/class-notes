# Learning Outcomes

By the end of this chapter, you should be able to:

1. Explain why large-scale numeric and tabular analysis becomes inefficient with only native Python lists and dictionaries.
2. Set up and verify a Python virtual environment using `venv`, install third-party packages with `pip`, and import NumPy and Pandas correctly.
3. Distinguish standard-library modules (`json`, `csv`) from third-party packages (`requests`, `numpy`, `pandas`) and choose the correct installation workflow.
4. Build and inspect NumPy arrays, including shape, dtype, indexing, slicing, and vectorized arithmetic.
5. Use core NumPy operations (aggregation, boolean masking, and broadcasting) for business metrics.
6. Create and inspect Pandas DataFrames from dictionaries, lists, and CSV files.
7. Perform practical DataFrame transformations including filtering, sorting, column creation, grouping, and summarization.
8. Combine NumPy and Pandas in a repeatable data-preparation workflow suitable for reports and dashboards.
